🔧 Critical Compatibility Fix

Problem

Empty SUITESPARSE_FORTRAN macros in SuiteSparse_config.h caused preprocessor syntax errors in C23. The stricter C23 preprocessor rejected empty macro definitions used in function-like macro expansions.

Solution

Set -DSUITESPARSE_USE_FORTRAN=OFF to force manual Fortran calling convention instead of relying on FortranCInterface module. This ensures proper macro expansion: 

#define SUITESPARSE_FORTRAN(name,NAME) name##_
#define SUITESPARSE__FORTRAN(name,NAME) name##_
