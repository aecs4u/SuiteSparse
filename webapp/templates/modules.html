📦 SuiteSparse Modules

SuiteSparse is a suite of sparse matrix algorithms. Each module specializes in different aspects of sparse matrix computation.

AMD - Approximate Minimum Degree

Ordering

Symmetric approximate minimum degree permutation. Reduces fill-in for sparse Cholesky and LU factorizations.

Use Case: Sparse matrix reordering for factorization

CHOLMOD - Sparse Cholesky

BLAS Intensive Factorization

Supernodal sparse Cholesky factorization and update/downdate. Heavily uses BLAS Level 3 operations.

Use Case: Positive definite systems, least squares

UMFPACK - Multifrontal LU

BLAS Intensive Factorization

Unsymmetric multifrontal sparse LU factorization. Solves general sparse systems using BLAS Level 3.

Use Case: General sparse linear systems

GraphBLAS - Graph Algorithms

Graph Theory Custom Kernels

Graph algorithms in the language of linear algebra. Implements the GraphBLAS C API standard.

Use Case: Graph analytics, network analysis

KLU - Circuit Simulation

Factorization

Sparse LU factorization optimized for circuit simulation matrices with partial pivoting.

Use Case: Circuit simulation, power networks

SPQR - Sparse QR

BLAS Intensive Factorization

Multifrontal sparse QR factorization for sparse least squares problems.

Use Case: Sparse least squares, rank detection

BTF - Block Triangular Form

Ordering

Permutes a matrix into block upper triangular form for easier solution.

Use Case: Decomposing systems into independent blocks

COLAMD - Column AMD

Ordering

Column approximate minimum degree permutation for sparse QR and Cholesky on A'A.

Use Case: Ordering for QR factorization

ParU - Parallel LU

Parallel Factorization

Parallel multifrontal sparse LU factorization with OpenMP acceleration.

Use Case: Large-scale parallel sparse solvers

LAGraph - Graph Algorithms

Graph Theory

Library of graph algorithms built on top of GraphBLAS.

Use Case: High-level graph analytics

SPEX - Exact Arithmetic

Exact

Sparse exact arithmetic for solving systems with rational numbers.

Use Case: Problems requiring exact solutions

Mongoose - Graph Partitioning

Partitioning

Graph partitioning and coarsening for sparse matrix computations.

Use Case: Graph partitioning, load balancing

🎯 BLAS Impact on Performance

Modules marked with BLAS Intensive show the most significant performance differences between BLAS implementations:

  • CHOLMOD: Up to 30% performance difference between BLAS vendors
  • UMFPACK: 15-25% performance variation depending on matrix structure
  • SPQR: 20-40% difference in least squares problems

These modules spend 70-90% of their time in BLAS Level 3 operations (matrix-matrix multiply), making BLAS selection critical for optimal performance.
