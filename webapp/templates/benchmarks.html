Each benchmark tests specific operations within SuiteSparse modules. Click on a benchmark to see its execution history and detailed statistics.

AMD_simple

Ordering Low BLAS

Module: AMD (Approximate Minimum Degree)

Tests basic sparse matrix ordering operations. Primarily integer operations with minimal BLAS usage.

Typical Time: 0.01-0.03 seconds
BLAS Impact: Minimal (< 5%)

CHOLMOD_quick

BLAS Level 3 Factorization

Module: CHOLMOD (Sparse Cholesky)

Supernodal Cholesky factorization benchmark. Heavy use of dense matrix operations via BLAS.

Typical Time: 0.02-0.04 seconds
BLAS Impact: High (70-80%)

UMFPACK_quick

BLAS Level 3 Factorization

Module: UMFPACK (Multifrontal LU)

Unsymmetric LU factorization with partial pivoting. Extensive BLAS Level 3 usage.

Typical Time: 0.02-0.04 seconds
BLAS Impact: High (60-75%)

GraphBLAS_quick

Graph Algorithms Custom Kernels

Module: GraphBLAS (Graph Algorithms)

Graph matrix operations using custom optimized kernels. Moderate BLAS interaction.

Typical Time: 0.02-0.05 seconds
BLAS Impact: Medium (30-40%)

💡 Benchmark Interpretation

BLAS-intensive benchmarks (CHOLMOD, UMFPACK) show the largest performance differences between BLAS vendors. These are the critical tests for evaluating BLAS implementations. Ordering benchmarks (AMD) serve as control tests to ensure consistent system behavior.
